# Paint Application

Draw with left mouse button.  
Right mouse button increases brush size.  
Press **R** (red), **G** (green), **B** (blue) to change color.  
Press **E** for eraser.

## Requirements
- Python 3.7+
- Pygame: `pip install pygame`

## How to Run
```bash
py -3.11 Practice10\Paint\main.py
