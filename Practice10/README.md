# Practice 10 – Three Pygame Games

This repository contains three classic arcade games implemented in Python using Pygame:

- **Racer** – avoid enemy cars and collect coins.
- **Snake** – classic snake game with progressive levels and increasing speed.
- **Paint** – simple drawing application with shapes, color selection, and eraser.

## Requirements

- Python 3.7 or higher
- Pygame library

Install Pygame:
```bash
pip install pygame
