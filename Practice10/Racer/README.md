# Racer Game – Avoid Enemies, Collect Coins

A highway racing game where you control a car, dodge enemy vehicles, and collect coins to increase your score. The game gets faster over time, and every 10 coins give a speed boost.

## Requirements
- Python 3.7+
- Pygame library

Install Pygame:
```bash
pip install pygame

## How to Run
```bash
py -3.11 Practice10\Racer\main.py
