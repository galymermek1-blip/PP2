# Practice 11 - Paint

This project extends the Paint application from Practice 10 using Pygame.

## Features from Practice 10

- Draw rectangle
- Draw circle
- Eraser tool
- Color selection (palette)
- Brush drawing (freehand)

## New Features in Practice 11

- Draw square (equal sides)
- Draw right triangle
- Draw equilateral triangle
- Draw rhombus
- Clean and commented code

## Tools

- Brush – freehand drawing
- Rectangle – draw rectangles
- Circle – draw circles
- Square – draw squares
- Right Triangle – draw right triangles
- Equilateral Triangle – draw equilateral triangles
- Rhombus – draw rhombus shapes
- Eraser – remove drawings
- Clear – clear the canvas

## Controls

- 1 – Brush  
- 2 – Rectangle  
- 3 – Circle  
- 4 – Eraser  
- 5 – Square  
- 6 – Right Triangle  
- 7 – Equilateral Triangle  
- 8 – Rhombus  
- C – Clear canvas  

## Colors

- R – Red  
- G – Green  
- B – Blue  
- Y – Yellow  
- P – Purple  
- O – Orange  
- K – Pink  
- L – Black  

## Additional

- Mouse is used to draw shapes
- Drag mouse to preview shapes before placing
- Brush size can be adjusted (+ / -)

## Technologies

- Python
- Pygame
