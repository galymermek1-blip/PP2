# Practice 11 - Pygame Projects

This practice contains three extended Pygame projects based on Practice 10:

- Racer
- Snake
- Paint

Each project includes new features and commented code.

## 1. Racer

### Features from Practice 10

- Player car movement
- Enemy car movement
- Random coins on the road
- Coin counter display
- Game over screen
- Sound and image support

### New Features in Practice 11

- Coins have different weights: 1, 2, 3
- Score increases based on coin weight
- Enemy speed increases after collecting N coins
- Code is commented

## 2. Snake

### Features from Practice 10

- Wall and border collision detection
- Self-collision detection
- Random food placement
- Food does not appear on the snake body
- Level system
- Speed increases with each level
- Score and level display

### New Features in Practice 11

- Food has different weights: 1, 2, 3
- Score increases based on food weight
- Food disappears after a certain time
- Code is commented

## 3. Paint

### Features from Practice 10

- Brush drawing
- Rectangle tool
- Circle tool
- Eraser tool
- Color selection
- Clear canvas

### New Features in Practice 11

- Draw square
- Draw right triangle
- Draw equilateral triangle
- Draw rhombus
- Code is commented

## Technologies

- Python
- Pygame
