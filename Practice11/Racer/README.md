# Practice 11 - Racer

This project extends the Racer game from Practice 10.

## Added features

- Random coins appear on the road.
- Coins have different weights: 1, 2, or 3.
- The coin counter is shown in the top right corner.
- Enemy speed increases after every N collected coin points.
- Code is commented.

## Controls

- Left Arrow: move left
- Right Arrow: move right
- R: restart after game over
- Q or Esc: quit after game over
