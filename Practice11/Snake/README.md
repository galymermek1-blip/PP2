# Practice 11 - Snake

This project extends the Snake game from Practice 10 using Pygame.

## Features from Practice 10

- Wall and border collision detection
- Snake self-collision detection
- Random food placement (not on snake body)
- Level system based on score
- Speed increases with each level
- Score and level display

## New Features in Practice 11

- Random food generation with different weights (1, 2, 3)
- Score increases based on food weight
- Food disappears after a certain time (timer)
- Clean and commented code

## Gameplay

The player controls the snake using arrow keys.  
The goal is to eat food and increase the score.

Different food types:
- Red → weight 1
- Orange → weight 2
- Yellow → weight 3

Food disappears after a few seconds if not eaten.

The game ends when:
- The snake hits the wall
- The snake collides with itself

## Controls

- ↑ Arrow: Move Up
- ↓ Arrow: Move Down
- ← Arrow: Move Left
- → Arrow: Move Right
