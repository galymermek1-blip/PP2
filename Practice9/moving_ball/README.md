# Moving Ball

## Description
This project is a simple interactive Pygame game with a moving red ball.

## Features
- White background
- Red ball with radius 25
- Ball moves with arrow keys
- Each key press moves the ball by 20 pixels
- Ball cannot leave the screen boundaries

## Controls
- Up Arrow
- Down Arrow
- Left Arrow
- Right Arrow

## Run
```bash
py -3.11 Practice9/moving_ball/main.py
