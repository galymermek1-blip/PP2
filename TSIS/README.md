SIS1 – PhoneBook

Extended contact management system using Python and PostgreSQL.

Main features:

contacts table
phones table
groups table
email and birthday fields
search, filter, sort
JSON / CSV import and export
stored procedures

TSIS2 – Paint

Paint application using Pygame.

Main features:

pencil tool
line tool
rectangle and circle
square, triangles, rhombus
brush size
flood fill
text tool
save canvas as PNG

TSIS3 – Racer Game

Arcade racer game using Pygame.

Main features:

main menu
traffic cars
coins
obstacles
power-ups
distance and score
leaderboard
settings

TSIS4 – Snake Game

Snake game using Pygame and PostgreSQL.

Main features:

username input
PostgreSQL leaderboard
personal best
poison food
power-ups
obstacles
settings
game screens
